# Ecommerce Monorepo

This workspace combines the storefront, dashboard, and API apps.

## Apps

- `apps/web` - Next.js customer storefront
- `apps/dashboard` - Vite admin dashboard
- `apps/api` - NestJS backend API

## Common Commands

```bash
pnpm install
pnpm dev
pnpm dev:web
pnpm dev:dashboard
pnpm dev:api
pnpm build
pnpm lint
pnpm typecheck
```

The original project folders in `C:\projects` were left untouched.
